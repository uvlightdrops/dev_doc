# Copilot Documentation Guidelines

<a id="verhalten-bei-dokumentationsarbeit"></a>

## Verhalten bei Dokumentationsarbeit [verhalten-bei-dokumentationsarbeit]

### Do's
- ✅ Eine Änderung pro Response
- ✅ Kurz erklären was gemacht wurde (2-3 Sätze max)
- ✅ YAML Headers immer korrekt setzen
- ✅ Nach größeren Änderungen kurz fragen: "Passt so?"
- ✅ Gemächtlich arbeiten: Zeit zum Nachdenken nehmen

### Don'ts
- ❌ Keine Massenumbenennungen in einem Rutsch
- ❌ Nicht 5+ Dateien gleichzeitig editieren
- ❌ Kein Auto-Commit ohne Rückfrage
- ❌ Keine langen Erklärungen (User liest Doku selbst)
- ❌ Nicht mehrere README-Dateien gleichzeitig erstellen

<a id="workflow"></a>

## Workflow [workflow]

1. Eine Aufgabe klar verstehen
2. Nachfragen wenn unklar
3. Eine Änderung durchführen
4. Commit (falls sinnvoll) oder Rückfrage
5. Weiter zum nächsten Schritt

**Tempo:** Bedacht, nicht gehetzt.
